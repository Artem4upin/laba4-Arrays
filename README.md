# Лабораторная работа: Обработка массивов

## Автор

Чупин Артем (Вариант 31)

## Цель

Понять устройство массива и оценку сложности основных операций. Научиться обрабатывать матрицы, вычислять итоги по строкам и столбцам, выделять диагонали и преобразовывать данные.

## Описание

Программа находит строки в которых положительных элементов больше чем отрицательных и вычисляет сумму четных элементов этой строки.

## Исходные данные

- Матрица C

## Ожидаемые результаты

Программа выводит три значения:

- Исходная матрица
- Найденые строки
- Суммы четных элементов строк
- Если подходящих строк нет - сообщение об их отсутствии
